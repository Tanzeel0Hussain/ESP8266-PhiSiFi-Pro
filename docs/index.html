Web flasher

Install directly from your browser

Connect a supported ESP8266 board over USB, select the serial device when your browser asks, and flash the current defensive firmware.

Use desktop Chrome or Microsoft Edge over HTTPS. A data-capable USB cable is required, and the browser will always ask you to approve the serial device.
📡

Nearby network inventory

View SSID, BSSID, channel, signal strength and advertised security mode from the ESP8266 dashboard.

🛡️

Defensive by design

The current firmware focuses on observation and configuration awareness instead of deauthentication, impersonation or credential collection.

⚙️

Reproducible delivery

GitHub Actions compiles the PlatformIO firmware, updates the browser-installable binary and publishes a downloadable release asset.

Quick start

01 · CONNECTAttach your ESP8266 board using a data-capable USB cable.
02 · INSTALLPress Install Firmware and approve the serial port requested by the browser.
03 · JOINAfter reboot, connect to ESP8266-Security-Lab using password securitylab.
04 · MONITOROpen 192.168.4.1 and press Scan now to refresh nearby networks.
Authorized use only. This project is intended for your own lab, classroom, and approved wireless-security observation. It does not provide credential collection or client-disruption features.
