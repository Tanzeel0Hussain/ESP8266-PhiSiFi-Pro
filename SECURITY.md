# Security and Responsible Use

ESP8266 Wireless Security Lab is maintained as a defensive, educational project for authorized environments.

## Scope

The current main-branch firmware is designed for passive Wi-Fi metadata observation. It does not intentionally disconnect clients, impersonate access points, or collect network credentials.

## Responsible Use

Use this project only on hardware, networks, and radio environments you own or are explicitly authorized to assess. Follow applicable laws, organizational policies, and local radio regulations.

## Reporting a Security Issue

If you discover a vulnerability in the firmware, local dashboard, build pipeline, or web installer, please open a GitHub issue without including secrets, private credentials, or sensitive third-party network information.

## Historical Versions

Older commits may contain experimental functionality that is no longer part of the current defensive project direction. The current `main` branch is the supported version.
